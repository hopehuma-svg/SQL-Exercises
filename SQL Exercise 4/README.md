
# NexBank SQL Practice: Set Operations

This repository contains my SQL solutions for the NexBank set operations training lab. The focus of these exercises is to implement `UNION` and `UNION ALL` operators to merge datasets from different branch structures, transaction logs, and internal bank departments.

## Project Overview

The lab explores how to handle relational data across multiple tables. It highlights the difference between deduplicating combined datasets and maintaining full historical logs for auditing.

### Topics Covered:
* **UNION Operations**: Removing duplicate rows when merging datasets like customer registers and product catalogues.
* **UNION ALL Operations**: Retaining all records for financial auditing, ATM log reconciliation, and general ledger streams.
* **Structural Integrity**: Aligning column counts and data types across divergent tables to ensure operational symmetry.
