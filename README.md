# BrightLearn Data Analytics: Exercise 01 - SQL Foundations
This repository contains my submission for Exercise 01 (SQL Fundamentals: SELECT & Filtering) as part of the BrightLearn Basic SQL course. 
## Project Focus
The purpose of this exercise is to build and practice foundational SQL query skills, focusing on data retrieval, sorting, filtering, and predicting query outputs. The assignment involves writing 10 structured queries against an `employees` database table and mapping out the expected output grids.
### Key Skills Practiced:
* **Data Retrieval:** Using `SELECT *` and isolating specific target columns.
* **De-duplication:** Applying `DISTINCT` to isolate unique records.
* **Sorting & Constraints:** Combining `ORDER BY` (ASC/DESC) with `LIMIT` thresholds.
* **Conditional Filtering:** Building logical criteria using `WHERE` clauses alongside `AND`, `OR`, `NOT`, and `IN` operators.
